# Magnificent Monsters GMR depletion dashboard

Live page: https://mastersquidwardo-blip.github.io/mamo/

Single-file model of Yu-Gi-Oh Magnificent Monsters (MAMO) Americas print, pack openings, and remaining Grand Master Rare chasability.

**This is not a Konami leak.** Print run `R` is inferred. Confidence is low until someone logs hundreds of boxes with GMR counts.

Open `index.html` locally, or use the Pages URL once it is live.
